第一步：淘宝开放平台账号申请

1
注册淘宝开放平台账号
  1. 访问 https://open.taobao.com/
  2. 点击"注册"按钮，使用淘宝账号登录
  3. 完成开发者实名认证（需要身份证信息）
  4. 等待审核通过（通常1-3个工作日）
2
创建应用获取密钥
  1. 登录开放平台控制台
  2. 点击"创建应用"
  3. 选择应用类型（建议选择"工具型应用"）
  4. 填写应用信息：
    • 应用名称：订单管理系统测试
    • 应用简介：用于测试订单回调功能
    • 回调URL：暂时填写任意URL，后续可修改
  5. 提交审核或申请沙箱权限
获取的关键信息：
  • App Key（应用标识）
  • App Secret（应用密钥）
  • 沙箱环境地址

必需软件
  • PHP 7.4+
  • MySQL 5.7+

快速启动命令：
# 1. 启动PHP服务（端口80） run_php.bat # 2. 启动内网穿透 start_ngrok.bat # 3. 访问测试 http://localhost/index.html

第三步：内网穿透配置

1
ngrok配置文件

项目已集成ngrok，配置文件位于项目根目录。

启动后会在 log/ngrok.log 生成访问日志。

2
获取临时域名
  1. 运行 start_ngrok.bat
  2. 等待启动完成（约10-30秒）
  3. 查看输出中的 Forwarding 地址，如：
    Forwarding http://abc123.ngrok.io -> http://localhost:80
  4. 记录这个URL，后续配置淘宝回调用
注意：ngrok免费版的域名每次重启都会变化，需要重新配置淘宝回调地址。

常见问题解答

Q1: 回调收不到怎么办？
A: 检查ngrok是否正常运行，确认回调URL可访问，检查防火墙设置。
Q2: 签名验证失败？
A: 检查App Secret是否正确，确认签名算法与淘宝要求一致。
Q3: 数据库连接失败？
A: 确认MySQL服务已启动，检查数据库用户名密码是否正确。
Q4: ngrok域名变了怎么办？
A: 免费版域名会变，需要重新配置淘宝回调地址。考虑使用付费版或Cloudflare。
